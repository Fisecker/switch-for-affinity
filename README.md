# Switch for Affinity

**Make Affinity by Canva feel like Adobe – in one click.** Free, open source, macOS.

Coming from InDesign, Illustrator or Photoshop? Switch for Affinity sets up Affinity so your hands already know where everything is:

| Affinity studio | works like | what changes |
|---|---|---|
| **Layout** | InDesign | shortcuts, toolbar, panels, InDesign “Fitting” (⇧⌘E, ⌥⌘E, ⌥⇧⌘E, ⌥⌘C, ⌥⇧⌘C) |
| **Vector** | Illustrator | shortcuts, toolbar, panels, optional fitting |
| **Pixel** | Photoshop | shortcuts, toolbar, panels, optional fitting |

## ⬇️ Download

**[Download the latest release (ZIP)](https://github.com/Fisecker/switch-for-affinity/releases/latest)** – unzip, double-click **Switch for Affinity**.

Requirements: macOS 12 or newer, Affinity by Canva (tested with 3.3), launched at least once.

## ⚠️ First launch: macOS security warning

Switch for Affinity is **not yet signed and notarized by Apple** – that requires the paid Apple Developer Program ($99/year), which will follow once the project can support it. Since **macOS Sequoia 15.1**, right-click → “Open” no longer works for such apps. Do this once:

1. Double-click **Switch for Affinity** → click **Done** in the warning (*not* “Move to Trash”).
2. Apple menu  → **System Settings → Privacy & Security** → scroll down.
3. Next to “Switch for Affinity was blocked…” click **Open Anyway**, confirm with password / Touch ID.
4. Double-click again → **Open Anyway**. From now on it opens normally.

Why this is safe: all source code is right here. The app only changes Affinity’s own settings, **backs everything up first**, can **restore everything** with one click and sends no data anywhere.

## What you can choose

- Language (English / Deutsch), keyboard (US / German)
- Dark or light UI, toolbar with 1 or 2 columns, font size, mono or colour icons, docked or floating context toolbar
- Colour profiles like Adobe Europe (Coated FOGRA39) or US (SWOP)
- Per program: shortcuts · tools · panels · fitting commands – each on/off
- **Restore…** puts Affinity back exactly as it was

Change settings any time: inside Affinity via **Affinity → Services → Switch for Affinity – Einstellungen**, or start the app again (it copies itself to Applications). Run it again after an Affinity update – new Affinity commands are kept.

## Limits

- Adobe commands that don’t exist in Affinity can’t get a shortcut (e.g. F-key panel shortcuts).
- Fitting commands use Affinity’s scripting interface (MCP, enabled automatically) and take about a second.
- macOS only for now. A Windows version may follow.

# Deutsch

**Affinity by Canva wie Adobe – mit einem Klick.** Kostenlos, Open Source, für den Mac.

Layout = InDesign, Vektor = Illustrator, Pixel = Photoshop: Tastenkürzel, Werkzeugleiste, Bedienfelder rechts und die InDesign-Anpassen-Befehle (⇧⌘E …).

**[⬇️ Neueste Version herunterladen (ZIP)](https://github.com/Fisecker/switch-for-affinity/releases/latest)** – entpacken, „Switch for Affinity“ doppelklicken. Voraussetzung: macOS 12+, Affinity by Canva (getestet mit 3.3), mindestens einmal gestartet.

### ⚠️ Erster Start: Sicherheitswarnung von macOS

Switch for Affinity ist **noch nicht von Apple signiert und notarisiert** – dafür braucht man das kostenpflichtige Apple Developer Program (99 $ pro Jahr); das kommt, sobald das Projekt es trägt. Seit **macOS Sequoia 15.1** lassen sich solche Apps nicht mehr per Rechtsklick → „Öffnen“ starten. Einmalig so:

1. „Switch for Affinity“ doppelklicken → in der Meldung auf **Fertig** klicken (*nicht* „In den Papierkorb legen“).
2. Apple-Menü  → **Systemeinstellungen → Datenschutz & Sicherheit** → nach unten scrollen.
3. Bei „Switch for Affinity wurde blockiert …“ auf **Trotzdem öffnen** klicken, mit Passwort / Touch ID bestätigen.
4. Nochmal doppelklicken → **Trotzdem öffnen**. Ab jetzt startet die App normal.

Warum das sicher ist: Der komplette Quellcode liegt hier offen. Das Programm ändert nur Affinity-Einstellungen, **sichert vorher alles**, kann **alles wiederherstellen** und sendet keine Daten.

Einstellungen später ändern: in Affinity über **Affinity → Dienste → „Switch for Affinity – Einstellungen“** oder die App erneut starten. Nach Affinity-Updates einfach nochmal ausführen.
